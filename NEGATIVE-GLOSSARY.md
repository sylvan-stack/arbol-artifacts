# Negative Glossary

Phrases the owner has prohibited in communication and documentation. Each entry gives questions that help an agent name the actual work. A mention of the phrase can still identify the entry or quote an exact source.

The second-level headings in this file each create a Mycel Cue Card.

## revised acceptance path

**Prohibited.** Rephrase this term in replies, progress updates, and documentation. State which tool or person acts, what they do, and what still needs to happen.

- Are these integration or end-to-end tests? If so, name the type of test and what it checks.
- Is the tool checking or recording package versions? Say which packages it checks or records and why.
- Is the tool moving saved files or starting a new version? Say which action is pending.

**Example.** “The tool still needs to record which versions of the four Drivers and the arbol cli it will use before it starts them.”

## shared arbol package

**Prohibited.** Use **arbol cli** instead.

- Which action does the arbol cli perform here? Name the command or describe what it does.
- Does the reader need an exact package or Build number? Give that identifier separately.
